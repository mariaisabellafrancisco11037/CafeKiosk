# Thesis Adviser Feature Pack

Added:
- Developer footer attribution on frontend pages.
- Email notification for pending cafe-owner registrations.
- Required owner declaration and phone number; accounts remain pending until System Admin approval.
- Owner-only store/menu customization writes.
- Admin greeting: Hello, Welcome to [Cafe Name].
- Unique Admin/Manager Approval ID plus PIN hierarchy for Staff refund/void approval.
- Demo Cafe products receive bundled category images if no product image exists.

Railway variable:
SYSTEM_ADMIN_NOTIFICATION_EMAIL=youraddress@gmail.com

Email delivery still uses the project's configured Resend sender.

Demo images in this build are bundled project illustrations, not external photographs. Replace them later with your own or properly licensed/referenced photos if the adviser requires unique photographs for every item.
