CafeKiosk - Dynamic POS Discounts & Promotions Update

What changed
------------
1. Staff POS and Manager POS no longer use a hard-coded Student/Senior/PWD discount list.
2. The Discount dropdown now loads the currently active promotions created by the Admin for that cafe.
3. Each option shows the promotion name, value, and its Admin-defined eligibility.
   Example: Hercor Student Discount — 10% off • Students
4. Selecting a promotion applies that exact promotion to the current order.
5. Choosing No Discount applies no promotion.
6. The backend re-calculates the selected promotion from MySQL before saving the order, so the client cannot invent a discount amount.
7. POS refreshes its promotion list whenever the browser tab regains focus, so Admin changes appear without a full redeploy.
8. If an Admin disables/deletes a promotion, it disappears from POS the next time the list refreshes.
9. The selected promotion's eligibility is recorded with the order automatically. The cashier does not need a separate Discount Eligibility field.

Example
-------
Admin creates:
  Name: Hercor Student Discount
  Type: Percentage
  Value: 10
  Eligibility: Students
  Status: Active

POS then shows:
  No Discount
  Hercor Student Discount — 10% off • Students

Selecting it on a P500 order produces a P50 discount and P450 total, subject to the Admin's scope/minimum/date/time rules.
