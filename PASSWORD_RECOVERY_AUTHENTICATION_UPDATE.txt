CafeKiosk Forgot Password + Authentication Update

Added:
- Forgot Password links for Admin, Manager, and Staff login pages.
- Registered-email recovery through the existing Resend HTTPS API.
- Cryptographically random 32-byte reset tokens. Only the SHA-256 token hash is stored in MySQL.
- 30-minute expiry (configurable with PASSWORD_RESET_EXPIRES_MINUTES).
- One-time reset links; previous links are invalidated when a new request is created.
- Generic forgot-password responses to reduce account/email enumeration.
- 60-second request throttling per account.
- Reset-link validation before the password form is enabled.
- New password must be at least 8 characters and contain a letter and a number.
- Cannot reuse the current password.
- Successful password reset clears failed login attempts and temporary lockout.
- Existing database user_sessions are revoked/cleared after reset when that table exists.
- Audit log entries for reset request and successful reset.
- Login brute-force protection: after 5 failed attempts, database-backed accounts are locked for 10 minutes.

Railway requirements:
RESEND_API_KEY
RESEND_FROM_EMAIL
RESEND_FROM_NAME (optional)

Public routes:
/forgot-password
/reset-password?token=...

API routes:
POST /api/auth/forgot-password
GET  /api/auth/password-reset/validate?token=...
POST /api/auth/password-reset

Note: System Administrator credentials are configured through Railway environment variables (SYSTEM_ADMIN_USER / SYSTEM_ADMIN_PASSWORD), not the cafe users table. This password-recovery flow intentionally applies to database-backed Cafe Owner/Admin, Manager, and Staff accounts.
